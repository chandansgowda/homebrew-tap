# homebrew-tap

Homebrew tap for [chandansgowda](https://github.com/chandansgowda)'s projects.

```bash
brew tap chandansgowda/tap
```

## Formulae

### posture-fix

AirPods-powered posture monitor for macOS —
[project repo](https://github.com/chandansgowda/posture-fix).

```bash
brew install chandansgowda/tap/posture-fix
posture-fix
```

> Formulae here build from source — requires macOS 14+ and Xcode.
> Add `--HEAD` to build the latest `main` instead of the tagged release.
